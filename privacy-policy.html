Privacy Policy

Application: Luma

Last updated: 2026

1. General Information

This Privacy Policy explains how information is handled when using the Luma mobile application (the "Application"). The Application is developed exclusively for Android devices using Kotlin.

2. Application Overview

Luma is a lightweight and minimalistic application designed to control the device flashlight. Its features include:

  • Turning the flashlight on and off
  • SOS mode with a repeating flash pattern (triple flash – pause – triple flash)

The Application does not require registration, login, or account creation.

3. Data Collection

Luma does not collect, store, or process any personal data.

Specifically, the Application:

  • Does not collect names, email addresses, phone numbers, or identifiers
  • Does not collect location data
  • Does not track user activity
  • Does not use analytics or tracking technologies

4. Permissions

The Application requests only the minimum required permission needed to access and control the device flashlight. No dangerous or unnecessary permissions are used.

5. Advertising

The Application displays a small banner advertisement at the bottom of the screen, provided by Google AdMob.

The developer does not collect or have access to any data processed by AdMob. Advertising-related data handling is governed by Google’s Privacy Policy.

Google Privacy Policy: https://policies.google.com/privacy

6. Third-Party Services

The Application uses the following third-party service:

  • Google AdMob — for displaying advertisements

7. Data Security

All application functionality is performed locally on the user’s device. No personal data is stored or transmitted.

8. Changes to This Policy

This Privacy Policy may be updated periodically. Any changes will be reflected on this page.

9. Contact

For any questions regarding this Privacy Policy, please contact the developer via the GitHub repository associated with this project.
